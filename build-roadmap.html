Priority order inside each pour

  3. Phase 1: Bridge read adapter → typed Decision→evidence→receipt → Work ledger/command history → Home KPI truth → thin Discover (Ideas / Conception tabs / Definitions).
  4. Phase 2: FLOW-01 thin · Delivery/Releases/Environments · Operate thin · Portfolio/Teams as needed. Still PAUSED unless a named write class opens.
  5. Later: Cost · Customers · Commercial/FLOW-04 · full 13-gate FLOW-01 · agents-as-actors · geography · Analytics/Improvement/EOL · System depth.
